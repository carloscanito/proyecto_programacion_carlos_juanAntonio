Cifras y Letras (Java)
Version simplificada del concurso televisivo Cifras y Letras desarrollada en Java para consola. Permite competir a dos jugadores por turnos en una misma terminal resolviendo pruebas de calculo matematico y agilidad linguistica.

Modos de juego

Modo Concurso: Se disputan todas las pruebas disponibles en orden. El ganador de cada prueba suma 1 punto en el marcador global (en caso de empate, nadie suma). Gana el jugador con mayor puntuacion global al finalizar.   
Proyecto de programación_ Cifras y Letras.pdf
Modo Rapido: Permite elegir y disputar una unica prueba de forma independiente.   
Proyecto de programación_ Cifras y Letras.pdf

Pruebas disponibles

La cifra exacta: A partir de un numero objetivo de 3 cifras y 6 numeros auxiliares (del 1 al 10), cada jugador dispone de 5 operaciones aritmeticas para acercarse lo maximo posible al objetivo.   
Proyecto de programación_ Cifras y Letras.pdf

La palabra mas larga: Se generan letras aleatorias (garantizando al menos 4 vocales y 4 consonantes). Cada jugador forma una palabra con las letras disponibles y el rival valida su existencia en espanol.   
Proyecto de programación_ Cifras y Letras.pdf

La calculadora humana: Prueba de calculo mental encadenado partiendo de un numero entre 1 y 100. Gana quien complete todas las operaciones en el menor tiempo posible (cada fallo anade una penalizacion de 20 segundos).

Instrucciones de ejecucion

Requisitos previos
Tener instalado el JDK de Java (version 8 o superior).
Pasos desde la terminal
Clona este repositorio en tu ordenador:
git clone https://github.com/carloscanito/proyecto_programacion_carlos_juanAntonio
Entra en la carpeta del proyecto:
cd tu-repositorio
Compila los archivos fuente .java:
javac *.java
Ejecuta el programa principal:
java modo_juego
